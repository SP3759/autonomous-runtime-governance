# Code of Conduct

ARG is a technical project. Contributions are evaluated on their technical merit and relevance to the governance use cases the framework addresses.

## Expected Behavior

- Be direct and specific in issues, pull requests, and discussions
- Provide context and reasoning for proposed changes
- Respect that maintainers may decline contributions that are out of scope
- Give credit where it is due

## Unacceptable Behavior

- Personal attacks or harassment
- Deliberately misleading technical claims
- Spam or self-promotional content unrelated to ARG

## Enforcement

Issues violating this code of conduct will be closed. Repeated violations result in removal from the project.

## Scope

This code of conduct applies to all project spaces including GitHub issues, pull requests, and discussions.
